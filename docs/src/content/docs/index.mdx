## Discover Panorama

<CardGrid stagger>
	<Card title="Flexible Node Data Store" icon="document">
		Store data in highly dynamic **Nodes** with namespaced fields, backed by transactional Schema constraints (both Preferred and Required).
	</Card>
	<Card title="WASM-Sandboxed Plugins" icon="setting">
		Build custom applications in Rust, compile to **wasm32-wasip1**, and run them safely with capability grants limiting network, filesystem, and storage access.
	</Card>
	<Card title="Panorama Query Language (PQL)" icon="magnifier">
		Query nodes and follow references using a Cypher-flavored syntax featuring mandatory space boundary isolation.
	</Card>
	<Card title="Built-in Event & Reactor Engine" icon="rocket">
		Implement **Eager** validation/transformation hooks, or **Deferred** post-commit background process pipelines to automate workflows.
	</Card>
</CardGrid>
